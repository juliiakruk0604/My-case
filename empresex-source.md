# Empresex — исходное содержание (из черновика UPWORKCOPY.md, Google Drive, 18.08.2026)

## Что за проект
Empresex — криптобиржа. Работодатель Yuliia: указана в опыте как «Web & Brand Designer».
Проверено отдельно: это действующая лицензированная криптобиржа (EU VASP) с реальными
транзакциями. Репутация на Trustpilot смешанная — на имя бренда опираться нельзя,
опираться нужно на ТИП продукта (регулируемый финансовый продукт, живые деньги).

## Позиционирование проекта (её формулировка)
«Empresex is a crypto exchange that needed to read as financial infrastructure —
not as a token launch.»

## Проблема (её формулировка, дословно)
«Crypto interfaces default to neon gradients, glass cards and feature walls. That signals
hype, and hype is the opposite of what someone feels before they move money.
The exchange widget — the only thing users came for — was buried five screens deep.»

## Решение (её формулировка, дословно)
«One typeface (Helvetica), three type sizes per screen, and a single warm light source
that crops differently on every page, so the whole product reads like frames of one
photograph. Structure is drawn with 1px rules and negative space instead of boxes and
shadows. Accent colour never exceeds 3% of any screen.»

## Отгружено (подтверждённые числа)
- 4 шаблона страниц — home, blog index, long-form article, mobile exchange
- 1 дизайн-система — токены, шкала, компоненты, состояния
- 3 брейкпойнта, настроенных вручную — 1440 / 1024 / 390, не авто-рефлоу
- Адаптивная фронтенд-сборка + анимация
- 0 стоковых ассетов — каждый визуальный элемент с нуля
- Срок: 4 недели, этапы define → system → screens → build
- Процесс: результат виден со второго дня, каждая неделя заканчивается кликабельным
