## Description (вставить целиком)

```
Empresex is a licensed EU crypto exchange — live, moving real money, not a concept.
The brief was one sentence: it has to look like it can be trusted with money within four seconds.

Direction ruled out — neon gradients, glass cards, feature walls. That performs hype,
and hype is the opposite of what someone feels before they move money.

Direction shipped — one typeface (Helvetica), three sizes per screen, a single warm light
source, structure drawn with 1px rules and negative space. Accent never exceeds 3% of a screen.

Delivered solo — every number has a method:
· 4 page templates — home, blog, article, mobile exchange
· 1 design system, reused across templates, not re-solved per screen
· 3 breakpoints hand-set (1440 / 1024 / 390), not auto-reflow
· 0 stock assets — every visual built from scratch
· ≤ 3% accent colour per screen — enforced as a system rule, checkable on any export
· 4 weeks: define → system → screens → build

What I am NOT claiming: screens to the exchange widget went from 5 (counted on the old
product) to a figure I have not re-measured on the live build — so there is no "after" number
here, not an estimate standing in for one.

Full case file — built as a terminal readout, every figure carries its method: [ссылка на кейс]
Solo. No agency, no subcontractors. Open for fintech / crypto / SaaS product design + front-end.
```

## Промах этого шота (честно)

Обложка показывает реестр цифр, а не сам продукт. Для дизайнерской аудитории это сильно
(метод виден), но фаундер за 4 секунды хочет увидеть и экран. Как только вставишь 03-desktop
и 04-mobile в кейс — во втором шоте покажи их, а этот оставь как «нулевой лист / метод».
