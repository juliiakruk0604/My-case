A crypto exchange rebuilt to read like financial infrastructure, not a token launch.

“Empresex is a crypto exchange that needed to read as financial infrastructure — not as a token launch.”

Yuliia Kruk, on the brief

Empresex is a licensed EU virtual-asset service provider — not a concept, a live exchange moving real accounts and real transactions. Nobody types a wallet address into something that looks like a landing page for a coin. The interface had to earn that before it asked for anything.

One rule ran the project: it has to look like it can be trusted with money within four seconds.

Ref. Direction Type — Decision log

Two ways to design a crypto product. One was ruled out before a single screen was drawn.

Direction A Rejected

The default pattern for crypto products: saturated gradients, translucent glass cards, features stacked to signal momentum. It performs energy. Energy reads as hype — exactly the wrong feeling to give someone right before they move money. Disqualified on function, not on style.

Direction B Adopted

“One typeface (Helvetica), three type sizes per screen, and a single warm light source that crops differently on every page, so the whole product reads like frames of one photograph. Structure is drawn with 1px rules and negative space instead of boxes and shadows. Accent colour never exceeds 3% of any screen.”

Same brief, two very different products. Only one of them looks like something you'd hand your transaction history to.
