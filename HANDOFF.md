> «I built the current platform using Lovable. The platform is functional, but I have taken it
> as far as I can by myself.»

> «It was originally built using AI-assisted ("vibe coded") development and now requires an
> experienced engineer to review the entire architecture and hand the system back to me in a
> production-ready state.»

> «If you're not familiar with AI coding tools (mainly Lovable), please don't apply.»

**Важная поправка к более раннему выводу.** Я сначала сказал: «ноль упоминаний вайбкодинга,
спроса нет». Это верно только для ДИЗАЙНЕРСКИХ вакансий от $5 000 — там ноль.
Но рядом существует отдельный и живой рынок: **починка того, что заказчик навайбкодил сам**.
Поток примерно 1,5 запроса в день. Продавать вайбкодинг некому — чинить его очередь.

Все лиды на Upwork. То есть блокер №1 стоит ровно между ней и деньгами.

## СТРАНИЦА КЕЙСА EMPRESEX (empresex-case.html) — сделана

Жанр зафиксирован в `SPEC.md`. Страница построена как **терминал в состоянии покоя**:
строки данных вместо карточек, `METHOD —` под каждым числом, журнал решений с названным
отвергнутым вариантом, слот `after [ — ]` оставлен пустым намеренно.

Дизайн-система взята с cosmos.so — заказчик прислала их CSS, вынуты настоящие токены:

```
--bg: #141414   --panel: #212020   --panel-inset: #323131
--ink: #FFF     --ink-2: #AEABAB   --ink-3: #918F8F     ← нейтрали ТЁПЛЫЕ, это ключевое
--accent: #EF7759 (тёплый, совпадает с правилом проекта про warm light source)
tracking: -0.025em / +0.025em    leading: 1.25 / 1.375 / 1.5
радиусы: 16px панель, 12px блок
```

Шрифты у референса лицензионные (cosmosOracle, Basis Grotesque Mono) — взять нельзя,
стоят замены: Helvetica-стек и JetBrains Mono.

**Два бага, найденных только просмотром рендера:**
1. `.reveal { opacity: 0 }` — страница рендерилась ПОЛНОСТЬЮ ПУСТОЙ без JS. Исправлено.
2. Анимация появления по скроллу ломала превью и скриншоты. Убрана целиком.

**Осталось слабым:** нет изображений 01–08 (в Drive и репозиториях их нет), слоты пустые;
великоват вертикальный провал между блоками; строка метода переносится посреди слова.
